# Cadastro de fornecedores

Projeto acadêmico do caso de uso **Manter Cadastro de Fornecedores**. O Spring Boot serve a interface HTML, CSS e JavaScript e acessa o PostgreSQL por JDBC.

- [Código fonte e instruções para executar](C%C3%B3digo%20Fonte/README.md)
- [Roteiro da apresentação](C%C3%B3digo%20Fonte/ROTEIRO_APRESENTACAO.md)
- [Front-end](Front-end/)
- [Diagramas de classes, sequência e MER](Diagramas%20Fornecedor/)

Para compilar, execute `./mvnw package` em **Código Fonte** ou `.\mvnw.cmd package` no Windows. O Dockerfile na raiz empacota o Java e o front-end no mesmo contêiner.
